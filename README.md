# Panthrex

I'm building Panthrex to bring CV writing, job search and interview preparation into one place. I want someone to be able to improve a CV, tailor it to a role, track the application and prepare for the interview without moving between several unrelated tools.

**[Visit Panthrex](https://www.panthrexai.com)** · **[Try the free ATS check](https://www.panthrexai.com/free-ats-check)**

## What's in the product

- **CV tools:** a resume builder, document import, writing assistance and role-specific tailoring.
- **Application checks:** CV-to-job-description comparisons, missing keywords and suggested improvements. The public ATS check does not require an account.
- **Job search and tracking:** job listings, matching tools and a tracker for applications.
- **Interview preparation:** practice questions, interview sessions and feedback.
- **Career support:** cover-letter drafting and a career assistant.

These tools support the application process. An ATS score is guidance, not a hiring prediction, and generated text needs the applicant's review.

## How I want Panthrex to work

I want the writing to sound like the person applying. Rewrites should preserve their experience, figures and achievements rather than inventing stronger claims. Suggestions should also fit the role and region instead of treating every application as a UK application.

I keep model usage limits and spending controls in the application. Features that depend on external services need their own configuration; a page being present does not mean its integration is configured in every environment.

## Technical overview

Panthrex uses Next.js, React and TypeScript. The application includes accounts and data storage, AI writing tools, job-listing integrations and billing.
